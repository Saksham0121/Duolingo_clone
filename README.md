# 🦉 Duolingo Clone

A full-stack Duolingo web app clone built as a portfolio-quality SDE assignment.

## Tech Stack
- **Frontend:** Next.js 14 (App Router, TypeScript, Tailwind CSS)
- **Backend:** Python FastAPI
- **Database:** SQLite (SQLAlchemy + Alembic)
